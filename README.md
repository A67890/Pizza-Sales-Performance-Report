# 🍕 Pizza Sales Performance Dashboard

## 1. Project Title / Headline

🍕 Pizza Sales Performance Dashboard – Interactive Sales Analysis Using Power BI

An interactive Power BI dashboard designed to analyze pizza sales performance, providing insights into revenue, order trends, product performance, pizza categories, and customer ordering patterns.

## 2. Short Description / Purpose

The Pizza Sales Performance Dashboard is an interactive data visualization project developed using Microsoft Power BI to analyze pizza sales data. It provides a comprehensive overview of sales performance through key performance indicators (KPIs), product-level analysis, category-wise sales distribution, and time-based trends.

The dashboard helps users identify top- and worst-performing pizzas, understand sales patterns, compare pizza sizes and categories, and gain meaningful insights into overall business performance.

## 3. Tech Stack

The dashboard was developed using the following tools and technologies:

- 📊 Power BI Desktop – Main platform used for dashboard development, data visualization, and interactive reporting.
- 📂 Power Query – Used for data cleaning, transformation, and preparation.
- 🧠 DAX (Data Analysis Expressions) – Used to create calculated measures, KPIs, and perform sales calculations.
- 📝 Data Modeling – Used to organize and analyze the single Excel table within Power BI.
- 📁 File Formats – Excel (`.xlsx`) for source data and Power BI (`.pbix`) for dashboard development.

## 4. Data Source

Source: Kaggle – Pizza Sales Dataset

The project uses a publicly available pizza sales dataset obtained from Kaggle in Excel format. The dataset consists of a single table containing pizza order and sales information, including order dates, order times, pizza names, pizza categories, pizza sizes, quantities sold, and pricing details.

The Excel dataset was imported into Power BI and used for data cleaning, transformation, calculations, and visualization.

## 5. Features / Highlights

### • Business Problem

Pizza businesses generate large volumes of sales data across different products, categories, sizes, and time periods. Analyzing raw sales data can make it difficult to identify top-performing products, understand customer ordering patterns, and recognize sales trends.

A centralized and interactive dashboard helps simplify this analysis by presenting important sales metrics and insights in a visual format.

### • Goal of the Dashboard

The primary objective of this dashboard is to provide an interactive overview of pizza sales performance that:

- Tracks key sales metrics such as revenue, orders, and quantity sold.
- Identifies the best- and worst-performing pizza products.
- Analyzes sales distribution across different pizza categories and sizes.
- Highlights monthly revenue trends.
- Identifies order patterns across different days of the week.
- Enables users to explore sales data using interactive filters.

### • Walkthrough of Key Visuals

1\. Key Performance Indicators (KPIs)

Displays important sales metrics at the top of the dashboard:

- Total Revenue
- Total Orders
- Average Order Value
- Total Pizzas Sold
- Average Pizzas Per Order

These KPIs provide a quick overview of overall sales performance.

2\. Interactive Filter Panel

Provides slicers to filter dashboard information based on:

- Month
- Pizza Category
- Pizza Size

These filters allow users to perform focused analysis across different sales dimensions.

3\. Top Pizza Performance

Highlights the best-performing pizzas based on three parameters:

- Top Pizza by Revenue
- Top Pizza by Orders
- Top Pizza by Quantity Sold

This helps identify products that contribute significantly to overall sales.

4\. Worst Pizza Performance

Identifies the lowest-performing pizzas based on revenue, number of orders, and quantity sold, helping highlight products that may require further attention.

5\. Monthly Revenue Trend

A line chart displaying monthly revenue from January to December. It helps identify revenue fluctuations and understand sales performance across different months.

6\. Sales Distribution by Pizza Category

A donut chart representing the percentage contribution of different pizza categories, including Classic, Supreme, Chicken, and Veggie.

7\. Sales Distribution by Pizza Size

Displays the percentage contribution of different pizza sizes, such as Small, Medium, Large, X-Large, and XX-Large, helping understand size-wise sales distribution.

8\. Orders by Day of Week

Illustrates the number of orders received on each day of the week, helping identify days with higher and lower order volumes.

9\. Total Pizzas Sold by Size and Category

Provides a comparison of pizza quantities sold across different sizes and categories, offering insights into product preferences.

10\. Total Revenue by Pizza Name

A treemap visualization displaying revenue contribution across individual pizza products, making it easier to compare product-level sales performance.

### • Insights & Use Cases

- Sales Performance Analysis: Monitor overall revenue, order volume, and quantity sold through centralized KPIs.
- Product Performance: Identify top- and low-performing pizzas based on different sales metrics.
- Category Analysis: Understand the contribution of different pizza categories to overall sales.
- Size Analysis: Evaluate sales distribution across different pizza sizes.
- Time-Based Analysis: Identify monthly revenue trends and variations in daily order volumes.
- Interactive Data Exploration: Use slicers to analyze specific months, categories, and sizes.
